# Distribution integration research

Research date: 2026-11-18.

- DDEX says ERN is used by labels/distributors to send release metadata to DSPs. A NewReleaseMessage describes one release and its resources, together with deals describing when, where and how it can be made available. ERN includes message formats, release profiles, and delivery choreographies over cloud storage or web services. DDEX states implementers need an Implementation Licence. Sources: [ERN overview](https://ddex.net/standards/electronic-release-notification-message-suite/) and [ERN standard implementation guidance](https://kb.ddex.net/implementing-each-standard/electronic-release-notification-message-suite-(ern)/).
- DDEX ERN 4 structure references parties, resources, releases, and deals; rights/deal terms include territories and validity periods, and takedowns are represented through deal updates. A release message should describe one product, not multiple releases. Source: [ERN 4 structure](https://kb.ddex.net/implementing-each-standard/electronic-release-notification-message-suite-(ern)/ern-4-explained/ern-4-structure).
- DDEX describes Release Delivery as an XML standard, ordinarily sent from a label/distributor to a DSP, covering full metadata and delivery terms. Source: [Release Delivery](https://ddex.net/standards-2023/release-delivery/).
- The official search result for the DDEX ERN suite says the latest published release is ERN 4.3.2. A current standards listing identifies ERN Part 1 baseline XSD 4.3.2; the official DDEX implementation licence must be addressed before shipping licensed schema files. Sources: [ERN suite](https://kb.ddex.net/implementing-each-standard/electronic-release-notification-message-suite-(ern)/) and [Standards specifications](https://kb.ddex.net/reference-material/standards-specifications).

Sources: [apex](https://montyxlabel.cyou) and [music-video release guide](https://user.montyxlabel.cyou/docs/creating-a-music-video).
